### whoami

- student at **42 Paris**, currently past the common core and into the parts where they hand you a setuid binary and say "good luck"
- mostly **backend & devops**: APIs, message queues, containers, and the YAML that holds them together
- recovering from a childhood of modding a certain $4 cube game in C++, which is how all of this started (lillac was NOT a mistake, it was just misunderstood)
- will rewrite your init system, your shell, your libc, and probably your kernel, purely out of spite
- currently into: binary exploitation, x86-64 assembly, low-level Linux userspace, NixOS and occasionally drinking water (keyword: occasionally)

### where i've been

plot twist: i was a PHP dev before i was a C dev. two years of apprenticeships, mostly spent helping a travel site escape its homegrown framework for modern Symfony. that's also where i first touched Docker, Kubernetes and RabbitMQ, so if you're wondering where the devops brainrot comes from, that's the origin story.

then 42 happened, and in 2025 i even crossed over to the other side of the piscine as a tutor. yes, i was the one walking behind you during exams.

and along the way: a BTS SIO (some Java i'd rather forget, plus a C compiler written in PHP that nobody asked for), Geometry Dash mods, a pile of Discord bots, an aim trainer whose name is too long to fit here, Vulkan experiments, a hobby x86 OS, a self-hosted k3s cluster (because paying for a PaaS is for people who sleep), and **night terrors**, my own C++ game engine that i will finish one day. probably.

### things i've built

| project | what it is |
| --- | --- |
| [**ft_transcendence**](https://github.com/vantavoids/ft_transcendence) | final project of the 42 common core, so naturally we built a Discord. Guilds, channels, roles & permissions, DMs, voice/video calls over WebRTC, all on an event-driven polyglot microservices backend (C#, RabbitMQ, SignalR) with Prometheus + Grafana watching it suffer. |
| [**minishell**](https://github.com/SkyDogzz/just-shell) | a POSIX shell from scratch in C: pipes, redirections, builtins. We mass-produced segfaults so you don't have to. Team project. |
| [**snow-crash**](https://github.com/vantavoids/snow-crash) | 42 security project: fifteen levels of historical computing war crimes, with walkthroughs and a one-command VM + attacker toolbox setup. |
| [**userspace_digressions**](https://github.com/vantavoids/userspace_digressions) | using systemd is cheating. A from-scratch init in C++ that parses the kernel cmdline, fscks and remounts root, and mounts your fstab, tested on an unattended Fedora VM. |
| [**ft_irc**](https://github.com/vantavoids/ft_irc) | an IRC server in C++98, with a few bots that probably should not exist. Team project. |
| [**ft_env**](https://github.com/vantavoids/ft_env) | a Docker image that emulates the 42 Paris workstation, so "it works on my machine" means something. |
| [**critervoid**](https://github.com/vantavoids/critervoid) | Criterion, GCC, Clang, gdb and valgrind in a box. `cd` into your project, run one command, get your tests. |
